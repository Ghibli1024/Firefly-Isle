# Code of Conduct

Firefly-Isle is built around sensitive medical workflows. The project expects
calm, precise, and humane collaboration.

## Standards

Expected behavior:

- Use welcoming and inclusive language.
- Respect different levels of clinical, technical, and open-source experience.
- Focus criticism on code, architecture, documentation, and evidence.
- Handle privacy, health, and security topics with extra care.
- Accept responsibility for mistakes and correct them quickly.

Unacceptable behavior:

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without explicit permission.
- Publicly disclosing security issues before maintainers can investigate.
- Derailing technical discussions with repeated bad-faith arguments.

## Enforcement

Maintainers may remove comments, close issues, reject PRs, or block accounts
that violate this code of conduct. Enforcement should be proportionate, clear,
and focused on preserving a safe project environment.
